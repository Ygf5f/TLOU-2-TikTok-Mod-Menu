TLOU2 TikTok Live Mod Menu

An experimental interactive mod for The Last of Us Part II Remastered on PC.

The mod allows TikTok LIVE viewer interactions to trigger in-game events and spawn NPCs.

Download

Download the latest beta from the Releases section.

Requirements
The Last of Us Part II Remastered
Node.js LTS
TikFinity with WebSocket enabled
Status

This is an experimental beta. The mod is currently being reviewed for distribution on Nexus Mods.
